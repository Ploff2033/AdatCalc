# Workflow: выгрузка путевых по месяцам с реестром

- Маршрут: small-change — расширение существующей выгрузки без изменения расчётов.
- Этап: acceptance.
- Цель: выгружать путевые листы в ZIP по папкам месяцев и добавлять корневой Excel-реестр с детализацией топлива по каждому документу.
- Границы и решения: требования описаны в proposal/spec/design. Любое количество документов выгружается ZIP; путёвки расположены в папках «Месяц ГГГГ», реестр `Реестр путевых.xlsx` — в корне. В реестре одна строка на документ; норма, факт, выдача и остатки берутся из тех же объектов, что печатная форма. Итоги нормы/факта/выдачи и числа путевых агрегируются помесячно и общие; баковые остатки не суммируются. Расчёты топлива и отдельная сводка не меняются.
- Согласование: 2026-11-18, пользователь ответил «Да, хорошо» на готовый пакет и ручное создание OpenSpec-артефактов при недоступном CLI.
- Реализация: Excel-реестр, месячные ZIP-папки, единый ZIP для одного и нескольких документов, расширение клиента.
- Проверки: `npm test` — PASS, 425/425 тестов, 0 пропусков; тесты включают ZIP-структуру, топливные значения, пробег, итоги и несуммируемые остатки. OpenSpec CLI недоступен, поэтому CLI-валидация не выполнялась. Git недоступен из-за неактивного пути Xcode Command Line Tools, состояние дерева не подтверждено.
- Следующий шаг: ручная проверка выгрузки на реальных данных пользователем; после подтверждения — штатная синхронизация и архивирование change.
