# Spec Delta

## Purpose

Равные права в реестре оплат у admin и у ссылки учредителя: по ссылке иногда работает и бухгалтер. Настройки остаются только у admin.

## ADDED Requirements

### Requirement: Равные права в реестре
Ссылка учредителя SHALL давать в реестре те же действия, что и admin:
- просмотр и экспорт;
- создание, правка и удаление заявок;
- файлы и автозаполнение из счетов;
- решения, «Платёжка готова» и её отмена;
- внесение и удаление оплат;
- пакетные действия.

Это заменяет ограничение прав учредителя из change `reestr-oplat` (только просмотр и решения).

#### Scenario: Оплата по ссылке учредителя
- **WHEN** по ссылке учредителя вносят оплату по заявке «Платёжка готова»
- **THEN** оплата сохранена, как у admin

#### Scenario: Новая заявка по ссылке
- **WHEN** по ссылке учредителя создают заявку с файлом
- **THEN** заявка создана, файл прикреплён

### Requirement: Настройки только у admin
Ссылка учредителя SHALL NOT давать доступ к Настройкам: справочникам категорий и подразделений, адресатам и событиям уведомлений, перевыпуску ссылки учредителя, тестовому сообщению. Запросы к ним по ссылке получают 403.

#### Scenario: Перевыпуск по ссылке
- **WHEN** по ссылке учредителя пытаются перевыпустить ссылку или изменить чат уведомлений
- **THEN** ответ 403, ничего не меняется

#### Scenario: Справочники по ссылке
- **WHEN** по ссылке учредителя пытаются добавить категорию
- **THEN** ответ 403; список категорий по ссылке читать можно, для фильтров и формы

### Requirement: Десктопный реестр по ссылке
Ссылка учредителя на экране шире 860 px SHALL открывать десктопный реестр: таблица, плитки, «Новая заявка», «Перетащите счета», карточка с правкой. Сайдбар с другими разделами и Настройками не показывается. На телефоне по ссылке открывается мобильный реестр с действиями оплат.

#### Scenario: Ссылка на ПК
- **WHEN** ссылку учредителя открывают на ПК с окном 1440 px
- **THEN** открывается таблица реестра с кнопками «Новая заявка» и зоной «Перетащите счета», без сайдбара и Настроек

#### Scenario: Ссылка на телефоне
- **WHEN** ссылку открывают на телефоне
- **THEN** мобильный реестр, в карточке заявки «Платёжка готова» есть форма «+ Оплата»

### Requirement: Manager и работники — без изменений
Права manager и работников по ссылкам заводов SHALL NOT меняться: доступа к реестру у них нет.

#### Scenario: Manager
- **WHEN** manager запрашивает реестр или любое его действие
- **THEN** ответ 403
