# Spec Delta

## Purpose

Справочники «Категории расходов» и «Подразделения реестра», по которым группируются заявки на оплату. С первого дня копятся данные о расходах по категориям и подразделениям.

## ADDED Requirements

### Requirement: Ведение справочников в Настройках
Admin SHALL вести в Настройках, в разделе «Реестр оплат», два справочника: «Категории расходов» и «Подразделения реестра». Значения можно добавлять, переименовывать, скрывать и возвращать. Пустые названия и дубли (без учёта регистра) не допускаются. В форме заявки значения только выбираются из списка, добавлять новые оттуда нельзя.

#### Scenario: Добавление категории
- **WHEN** admin добавляет категорию «Аренда»
- **THEN** «Аренда» появляется в выборе категории в форме заявки

#### Scenario: Дубль
- **WHEN** категория «Материалы» уже есть, и admin добавляет «материалы»
- **THEN** система отклоняет добавление

### Requirement: Переименование
Переименование значения SHALL менять его название везде, в том числе в уже созданных заявках и в экспорте.

#### Scenario: Переименование подразделения
- **WHEN** admin переименовывает «Стройка» в «Стройка ЖК Солнечный»
- **THEN** все заявки, где было «Стройка», показывают новое название

### Requirement: Скрытие вместо удаления
Значение, использованное хотя бы в одной заявке, SHALL NOT удаляться. Его можно только скрыть: оно пропадает из выбора в форме, но остаётся в старых заявках и доступно в фильтрах. Неиспользованное значение можно удалить.

#### Scenario: Скрытие используемой категории
- **WHEN** admin скрывает категорию «Топливо», по которой есть заявки
- **THEN** при создании заявки «Топливо» не предлагается, старые заявки продолжают показывать «Топливо»

#### Scenario: Удаление используемого значения
- **WHEN** admin пытается удалить подразделение, по которому есть заявки
- **THEN** система отклоняет удаление и предлагает скрыть значение

### Requirement: Независимость от других справочников
Справочники реестра SHALL NOT быть связаны с заводами (`plants`) и категориями ДДС. Изменение одного не меняет другое.

#### Scenario: Новый завод
- **WHEN** admin создаёт новый завод в Настройках
- **THEN** список подразделений реестра не меняется
