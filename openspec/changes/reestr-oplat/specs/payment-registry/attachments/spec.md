# Spec Delta

## Purpose

Файлы к заявкам на оплату: счета, договоры, платёжки. Admin прикладывает их, а учредитель и получатели экспорта открывают их по ссылке. Это заменяет облачную папку со счетами.

## ADDED Requirements

### Requirement: Прикрепление файлов к заявке
Admin SHALL иметь возможность прикрепить к заявке до 10 файлов. Допустимые типы: изображения jpeg, png, webp и PDF. Каждый файл загружается отдельно от формы заявки. У файла есть тип: «Счёт», «Договор», «Платёжка» или «Прочее» (по умолчанию «Счёт»). Файлы необязательны.

#### Scenario: PDF-счёт
- **WHEN** admin прикрепляет PDF размером 198 КБ с типом «Счёт»
- **THEN** файл сохраняется и показывается в заявке с именем, размером и типом

#### Scenario: Одиннадцатый файл
- **WHEN** к заявке уже прикреплено 10 файлов, и admin добавляет ещё один
- **THEN** система отклоняет загрузку с сообщением о лимите в 10 файлов

#### Scenario: Недопустимый тип
- **WHEN** admin прикрепляет файл .docx, .xlsx или .zip
- **THEN** система отклоняет загрузку с сообщением о допустимых типах

#### Scenario: Скриншот из буфера
- **WHEN** на ПК admin вставляет изображение из буфера обмена (Ctrl+V) в форме заявки
- **THEN** изображение прикрепляется как файл заявки

### Requirement: Ограничение размера
Система SHALL принимать PDF размером не более 10 МБ. Изображения сжимаются на устройстве перед отправкой, как фото чеков ДДС. Если файл после сжатия всё равно больше 10 МБ, система его отклоняет.

#### Scenario: Большой PDF
- **WHEN** admin прикрепляет PDF размером 12 МБ
- **THEN** система отклоняет загрузку с сообщением о лимите 10 МБ

#### Scenario: Большое фото
- **WHEN** admin прикрепляет фото 8 МБ с телефона
- **THEN** фото сжимается перед отправкой и сохраняется

### Requirement: Платёжка к оплате
Admin SHALL иметь возможность прикрепить к строке оплаты один файл платёжки (те же типы и лимиты). Он не входит в лимит 10 файлов заявки.

#### Scenario: Оплата с платёжкой
- **WHEN** admin вносит оплату и прикрепляет PDF платёжки
- **THEN** файл показывается у этой строки оплаты

### Requirement: Доступ к файлу по ссылке
Каждый файл SHALL открываться по постоянной ссылке без входа в систему. Имя файла в ссылке криптослучайное (не менее 128 бит), поэтому подобрать его невозможно. Исходное имя файла хранится отдельно и показывается в интерфейсе.

#### Scenario: Открытие из экспорта
- **WHEN** бухгалтер нажимает на ссылку файла в выгруженном Excel, не будучи в системе
- **THEN** файл открывается

#### Scenario: Подбор ссылки
- **WHEN** кто-то запрашивает файл реестра по произвольному имени
- **THEN** система отвечает «не найдено»

### Requirement: Просмотр на телефоне
На телефоне учредитель SHALL видеть миниатюры файлов в карточке заявки. Фото по нажатию открывается во весь экран, PDF — во встроенном просмотрщике телефона.

#### Scenario: Фото во весь экран
- **WHEN** учредитель нажимает на миниатюру фото счёта
- **THEN** фото открывается во весь экран, с возможностью увеличить и закрыть

### Requirement: Удаление файлов
Admin SHALL иметь возможность удалить файл заявки или платёжку. Вместе с записью удаляется и сам файл на сервере, после чего ссылка перестаёт открываться.

#### Scenario: Удаление файла
- **WHEN** admin удаляет файл из заявки
- **THEN** файл пропадает из заявки, а его ссылка отвечает «не найдено»

### Requirement: Файлы ДДС не затрагиваются
Хранение, лимиты и формат фото чеков ДДС SHALL оставаться без изменений.

#### Scenario: Чек ДДС
- **WHEN** работник прикладывает фото чека к записи ДДС
- **THEN** действуют прежние правила ДДС: только изображения, до 3 МБ
