# Spec Delta

## Purpose

Доступ учредителя к реестру оплат с телефона по постоянной ссылке без пароля, по образцу ссылок работников. Учредитель видит только реестр и принимает решения.

## ADDED Requirements

### Requirement: Ссылка учредителя
Система SHALL хранить один токен учредителя. Admin видит его в Настройках в виде ссылки и может скопировать. Открывая ссылку, учредитель попадает сразу в реестр, без экрана входа.

#### Scenario: Вход по ссылке
- **WHEN** учредитель открывает свою ссылку на телефоне
- **THEN** открывается реестр оплат в мобильном виде, пароль не запрашивается

#### Scenario: Ссылка на конкретную заявку
- **WHEN** учредитель открывает ссылку с токеном и номером заявки (например, из Telegram)
- **THEN** открывается карточка этой заявки с кнопками решения

#### Scenario: Неверный токен
- **WHEN** открыта ссылка с несуществующим токеном
- **THEN** реестр не открывается, показывается сообщение «Ссылка недействительна»

### Requirement: Перевыпуск ссылки
Admin SHALL иметь возможность перевыпустить ссылку учредителя. Старая ссылка, включая ссылки в отправленных Telegram-сообщениях, сразу перестаёт работать.

#### Scenario: Перевыпуск
- **WHEN** admin нажимает «Перевыпустить», а затем кто-то открывает старую ссылку
- **THEN** старая ссылка отвечает «Ссылка недействительна», новая работает

### Requirement: Права учредителя
По своей ссылке учредитель SHALL:
- видеть список, карточки, файлы и итоги реестра;
- менять фильтры;
- выгружать Excel;
- принимать и менять решения.

Учредитель SHALL NOT создавать, править и удалять заявки, оплаты и файлы. Другие разделы программы (заказы, ДДС, дашборд, настройки и т. д.) ему недоступны.

#### Scenario: Другие разделы
- **WHEN** учредитель по своей ссылке пытается открыть ДДС или Настройки
- **THEN** раздел недоступен, навигация показывает только реестр

### Requirement: Решение с телефона в одно нажатие
На телефоне в списке у заявок, ожидающих решения, SHALL быть кнопки «Одобрить», «Отложить» и «Отклонить». «Одобрить» без открытия карточки одобряет всю Сумму. Уменьшить «К оплате» можно в карточке заявки.

#### Scenario: Одобрение из списка
- **WHEN** учредитель нажимает «Одобрить» у заявки на 27 352,00 прямо в списке
- **THEN** заявка одобрена с «К оплате» 27 352,00 и переходит в группу «Одобрена / Частично»

### Requirement: Доступ admin и manager не меняется
Вход по паролю, права admin и manager, ссылки работников заводов и общая ссылка работников SHALL работать как прежде. Токен учредителя не даёт доступа к API, кроме реестра.

#### Scenario: Токен учредителя на чужом API
- **WHEN** с токеном учредителя запрашивают список заказов или записей ДДС
- **THEN** система обрабатывает запрос как анонимный, без доступа к данным, закрытым для анонимов
