# Правила работы

Для запросов на изменение проекта, исправление ошибок и продолжение задач
автоматически читай и применяй [sdd-task](./.agents/skills/sdd-task/SKILL.md).
Для вопросов, объяснений и обсуждения идей без запроса на выполнение процесс
не запускай. Явные указания пользователя имеют приоритет.

Пользователь определяет желаемое поведение и принимает результат. Агент
исследует проект, выбирает маршрут, уточняет существенные решения, готовит
артефакты, реализует и проверяет согласованное.

Правила предметной области и проверок находятся в
[OpenSpec config](./openspec/config.yaml). Читай их перед изменениями.
Для нового поведения требуется одно согласование готового пакета перед кодом.
Однозначное восстановление действующей спеки допускается без этого согласования.
После согласования работай самостоятельно в его границах. Не спрашивай повторно
об уже разрешённых действиях. Новые продуктовые решения согласовывай отдельно.
Архивирование — после подтверждения пользователем проверки на реальных данных.

Навыки OpenSpec в `.claude/skills/` являются локальными и исключены из Git.
Координатор содержит основной договор работы и порядок действий на случай их
отсутствия. Не считай наличие инструкции доказательством наличия CLI.
